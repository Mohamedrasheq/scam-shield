What to know

  • Our own test set gave ~98–99%. Test B shows about 90%, which is closer to real life.
  • Links are masked to <URL>, so the model cannot see fake-looking domains. Many missed scams depend only on the domain.
  • Test B has no long or multi-line messages, so it does not test that weakness.
  • Test B is now “seen”: don’t tune the model to its mistakes. A future check needs another fresh set.
